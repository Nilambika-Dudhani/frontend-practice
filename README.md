# Frontend Practice

A collection of frontend practice projects and UI designs built using **HTML and CSS**.

## 📌 About

This repository contains various web pages and UI designs that I have created while practicing frontend development. The projects focus on building responsive layouts, improving CSS skills, and recreating common website interfaces.

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📂 Projects

Some of the projects included in this repository:

* 🔐 Login Page
* 🛒 Shopping Website Homepage
* 🌐 Landing Pages
* 🎨 Various UI Designs
* 📱 Responsive Web Page Practice

More projects will be added as I continue learning and improving my frontend development skills.

## 🎯 Goals

* Improve HTML and CSS skills
* Practice responsive web design
* Learn modern UI layouts
* Build clean and user-friendly interfaces
* Prepare projects for future frontend development work

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/Nilambika-Dudhani/frontend-practice.git
```

2. Open the project folder.

3. Open the desired project's `index.html` file in your browser.
